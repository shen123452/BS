## 两个数据库的职责

| 项目 | MySQL 业务库 | PostgreSQL 向量库 |
|---|---|---|
| 运行方式 | Windows 服务 MySQL57 | Docker 容器 hospital-triage-pg |
| 实测版本 | MySQL 5.7.25-log | PostgreSQL 16.15 / pgvector 0.8.6 |
| 应用连接地址 | 127.0.0.1:3306 | 127.0.0.1:5433 |
| 库名 | hospital_triage | hospital_triage_vector |
| 本地开发连接账号 | root | hospital_vector_user |
| 表 | 15 张业务表 | public.knowledge_embedding |
| 访问方式 | MyBatis-Plus + 自定义 Mapper SQL | JdbcTemplate/JdbcClient |

MySQL 保存用户、档案、排班、预约、病历、问诊、Agent 记录、知识文档和片段正文。PostgreSQL 仅保存片段向量及其 chunk_id、空间、维度与状态。应用不进行跨库事务或跨库外键。

## 初始化与权限

- MySQL 目标库创建前未发现同名库；已执行 01_mysql_schema.sql，确认 15 张 InnoDB 表，15 个主键、15 个唯一约束、29 个外键。默认 utf8mb4_unicode_ci；本机 innodb_default_row_format=dynamic、innodb_large_prefix=ON。
- MySQL 本地开发直接使用已有 root 账号。MySQL 5.7 不执行 CHECK，Service 层必须验证状态、范围和跨字段规则。
- PostgreSQL 镜像为 pgvector/pgvector:pg16。容器仅映射 127.0.0.1:5433 到容器 5432，使用独立数据卷 hospital-triage-pgdata，重启策略 unless-stopped。
- PostgreSQL 已执行 02_postgresql_schema.sql，创建 vector 扩展、向量表、索引、约束及范数维护触发器。
- PostgreSQL 本地开发直接使用容器初始化账号 hospital_vector_user；保留其初始化密码，通过环境变量提供，不写入项目文件。
- 网站采用普通管理系统的三角色权限：sys_user.role 为 ADMIN、DOCTOR、PATIENT。后端负责角色和数据归属检查，不把数据库连接账号作为网站角色。
