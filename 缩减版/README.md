## 双数据库设计

- MySQL 5.7.25+/InnoDB：16张表，保存门诊业务、问诊/智能体记录、知识文档、片段正文和 AI 凭据。MySQL 5.7 不执行 CHECK 约束，枚举、范围和跨字段规则由后端校验。
- PostgreSQL 16 + pgvector：1张knowledge_embedding表，保存向量、片段ID映射和向量空间信息；首版执行精确余弦TopK检索。
- Java负责解析、切分和调用Embedding模型；先从MySQL取得有效候选片段ID，再在PostgreSQL过滤后排序，最后回MySQL取来源和正文。
- 两库通过任务状态、chunkId幂等写入和完整性校验保持最终一致，不建立跨库外键或分布式事务。HNSW/IVFFlat为后续选做，数据库故障和跨库重试纳入验收。
