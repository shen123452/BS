# 普通门诊三端页面

模式：Operate。依据已确认的《缩减版/页面与交互设计.md》，沿用其蓝白管理系统视觉基线。首批范围仅覆盖已实现接口。

## Direction contract

THESIS：让患者预约、医生接诊、管理员维护成为可连续操作的真实流程。页面以工作内容和下一步操作为中心。

OWN-WORLD：继承已明确的 #1D4ED8 主色、白色工作区、#F5F7FB 背景、中文系统字体、8px 控件和 12px 容器圆角；统一 Element Plus 与 SVG 图标。

STORY：登录自动进入对应角色；空库先创建科室、医生和排班，患者完善档案后预约，医生当天接诊、保存并提交七段病历。

FIRST VIEWPORT：患者顶部导航、左侧任务标题、右侧下一步按钮、下方真实预约；管理与医生固定 220px 侧栏和 64px 顶栏，筛选紧接任务标题，工作表格占主要区域。手机患者导航换行，操作保持 44px 高。

FORM：精确规格直接实现，结构和视觉由现有页面文档固定；无开放视觉世界选择。关键交互为预约确认前刷新号源、草稿版本冲突保留正文。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 最后修复和证据

复查后修复：患者档案 dirty/路由离开和浏览器关闭提示，重载确认，保存期间锁定字段；医生工作台显示本人三个真实状态数量、就诊说明并指引年龄/健康信息查看接诊详情；预约场次查询失败在刷新列表后仍保留并提供原场次重试；病历编辑持续展示患者姓名、挂号号与时间；表单边界提升至近白底3:1，患者和医生手机高频点击区达到44px，日期按钮增加aria-pressed、导航增加aria-current。未替换颜色、结构或组件系统。
