1. **运行持久事件**：`agent_run_event`（运行级序号唯一、PATIENT/ADMIN 可见性分离）；AgentStore 在创建/步骤开始/结束/校验/结果/失败取消时写入，患者事件只含公开标签与状态，事件写入失败不阻断业务。

## 操作边界

不重建现有业务数据库、不清理账号、不修改既有密码、不访问阿里云 ECS。阶段一迁移仅新增表/种子/增列，幂等可重复执行。集成测试仅回滚事务或按自己创建的明确 ID 清理虚构资料（前缀 `phase1_`）。克隆仓库不能恢复本机数据库内容；本地服务继续保持运行。
