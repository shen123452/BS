# 问诊与导诊接口说明

更新日期：2026-10-13。本文记录已实现首版；目标规格见[缩减版](../缩减版/README.md)，未完成项见[开发进度](开发进度.md)。

## 通用约定

统一 `/api` 前缀，认证为 `Authorization: Bearer <token>`。普通响应为 `code/message/data/traceId`，ID 使用字符串传输；患者身份从登录账号取得，客户端不能指定 patientId。患者只能操作本人资源，管理员接口仅 ADMIN 可用。

## 患者流程

| 方法 | 路径 | 功能 |
|---|---|---|
| POST/GET | `/patient/consultations` | 创建/分页读取本人会话 |
| GET | `/patient/consultations/{id}` | 读取会话、摘要版本与确认状态 |
| GET | `/patient/consultations/{id}/messages` | 恢复本人消息 |
| POST | `/patient/consultations/{id}/messages` | 发送消息，SSE 返回 `meta/delta/done/error` |
| POST | `/patient/consultations/{id}/cancel` | 按 operationId 取消当前流式操作 |
| PUT | `/patient/consultations/{id}/summary` | 保存或确认结构化摘要 |
| POST | `/patient/triage-runs` | 创建导诊任务，HTTP 202 |
| GET | `/patient/triage-runs/{id}` | 轮询状态、公开步骤及结果关联 |
| POST | `/patient/triage-runs/{id}/cancel` | 取消本人任务 |
| GET | `/patient/triage-results/{id}` | 读取推荐、证据、场次快照及能否预约 |

摘要请求包含 `summary`、`expectedSummaryVersion`、`confirm`。摘要包括主诉、持续时间、严重程度、伴随/否定症状及五项危险信号；每项危险信号只能为 YES、NO、UNKNOWN。须先核对并确认，不能把未知当作否定。继续发送新消息会更新摘要版本并使旧推荐失效。

创建任务请求包含 `sessionId`、`summaryVersion`、`clientRequestId`。同一请求号绑定会话和摘要版本，重试复用请求号；内容不一致返回冲突。创建后前端每两秒轮询，终态停止。任务仅提供公开阶段，不返回模型隐藏推理。

任务状态包括 QUEUED、RUNNING、SUCCEEDED、DEGRADED、FAILED、CANCELLED。超时按失败终止，并记录公开错误说明。明确急症不调用模型生成普通门诊推荐；证据不足可降级，信息不足要求补充。

## 预约关联

普通预约可不带 `triageResultId`。由结果页预约时携带字符串结果 ID，后端重新检查本人归属、有效期限、摘要确认/版本、最新结果、风险和推荐科室集合。跨出推荐/备选科室时前端清除关联，不能绕过校验。场次余号以预约提交时的数据库条件更新为准，结果中的场次快照不保证保留号源。

## 三个只读工具与预算

| 工具 | 数据来源与限制 |
|---|---|
| `searchMedicalKnowledge` | 当前向量空间内已启用 READY 文档；topK 为 1～5，引用须为本轮实际命中片段 |
| `findDepartments` | 实际启用科室目录，不接受外部患者身份 |
| `findAvailableSchedules` | 实际七日可预约日期范围，按有效科室查询真实排班 |

最多 4 轮模型调用、6 次工具调用、60 秒总时限。工具参数、工具名和调用 ID 均校验；知识工具最多 30 秒，SQL 工具与最终校验最多 3 秒，且不能超过剩余总时限。取消、超时和摘要变化后，晚回调不得发布结果。

## 管理员入口

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | `/admin/agent-tools` | 工具名称、用途及只读标记 |
| GET | `/admin/agent-runs` | 状态筛选和分页 |
| GET | `/admin/agent-runs/{id}` | 任务公开步骤 |
| GET | `/admin/statistics` | startDate/endDate，日期范围 1～93 天；预约按就诊日，导诊按创建日统计 |

知识上传、重试、启停、片段分页和检索入口见[后端 README](../hospital-server/README.md)。上传和检索会实际调用 Embedding 服务，正常启动与自动化测试不调用付费模型。

## 当前验证边界

工具参数、引用防伪、急症拦截、未知风险、摘要失效、任务取消/超时/晚回调及幂等已有测试；导诊集成测试使用真实 MySQL 和模型/知识测试替身。隔离浏览器测试验证表单与任务交互，不代表真实模型完整业务通过。完整百炼联调、医学效果、维护重建与历史恢复仍需后续验收。
