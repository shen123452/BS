## 填充与复核工具

工具：`hospital-server/scripts/seed-demo.mjs`。仅允许调用 localhost / 127.0.0.1 的系统 API，通过服务业务校验创建账号、排班、预约、取消和病历。管理员可在本机环境提供 `DEMO_ADMIN_PASSWORD`（可选 `DEMO_ADMIN_USERNAME`），或复用已登录的 WebBridge 页面；工具不会获取或输出该页面的登录令牌。

```powershell
# 预览计划，复用已登录的 WebBridge 页面。
node hospital-server/scripts/seed-demo.mjs --browser-session hospital-demo-data --dry-run

# 环境已有管理员和演示账号密码时，只读复核。
node hospital-server/scripts/seed-demo.mjs --verify-only
```

首次执行随机生成演示账号密码，仅输出一次；之后执行应从环境提供原 `DEMO_ACCOUNT_PASSWORD`，不会重置已有密码。同一预约使用固定请求号；演示对象先按清单与 ID 核对，发现同名未登记对象时停止。当天下午在 13:25 前运行会补当天排班与两份病历，其他时间只准备未来场次。跨日重新填充会补滚动六天排班和新日期预约；仅查看数据时使用 `--verify-only`。

本机批次清单位于 `.cache/demo-data/manifest.json`，记录每项确切 ID、日期和核验结果，不含密码或令牌；目录已被 Git 忽略。保留清单可供后续精确识别本批数据；不要直接按名称批量删除或重建数据库。
