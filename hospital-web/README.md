# 前端页面

Vue 3.5.22、Vite 6.3.6、Element Plus 2.11.4、Vue Router 4.5.1、Axios 1.12.2。界面采用既有蓝白医疗管理设计，登录后按账号角色进入对应工作空间。

## 本地启动

1. 在 IDEA 中正常运行后端 `HospitalApplication`，后端地址为 `http://127.0.0.1:8082`。
2. 首次进入本目录运行 `npm install`；已有依赖时不用重复安装。
3. 在本目录运行 `npm run dev`，或从 IDEA 的 npm 窗口运行 `dev`。
4. 打开 `http://127.0.0.1:5173`。后端和前端都启动后才可登录。

Vite 将 `/api` 转发到本地 8082，不需要在前端填写数据库或百炼密钥。管理员使用已初始化账号；患者公开注册，医生由管理员创建。账号密码不保存在前端源码。

## 关键交互

- Token 仅在当前浏览器标签页的 sessionStorage 保存。关闭标签页后需重新登录；每次进入受保护页面由后端重新确认身份。
- 预约确认前刷新场次；请求超时或服务错误时保存原请求号和原正文，继续确认复用请求。收到明确成功/拒绝后清除待确认请求。
- 患者病史区分“未提供”“明确无”“有”。未知年龄不显示为 0。
- 取消以服务端期限和预约状态为准；场次停用导致不可查询时仍可提交取消，由后端核验。
- 七段病历手动保存；版本冲突保留正文，提供复制与重新载入；离开未保存病历需确认。提交先保存正文，再按最新版本提交完成。
- 错误保留输入，显示中文原因与问题编号；列表提供重新加载。患者适配 375/768/1440px，管理表格在自身区域横向滚动。
- AI 问诊使用实际 SSE 事件，退出页面时中止当前连接；症状确认区分危险信号的“有”“无”“未知”，提交失败保留表单与请求号。
- 导诊任务轮询实际后端状态，展示公开步骤与已验证的知识来源；按服务端结果决定能否预约，旧摘要、过期或风险不满足时不能关联预约。
- 知识资料异步处理，失败可重试；检索相似度不表示医学概率。统计按实际记录聚合，空库显示真实空状态。
