已逐张读取项目 `原型图/1.png` 至 `原型图/11.png`，结合原始功能说明整理为适合毕设与实习展示的开发规格。本目录是文档交付，尚未实现应用或验证模型效果。

建议阅读顺序：

1. [智能导诊系统开发文档](智能导诊系统开发文档.md)：定位、原型审阅、P0/P1/P2、架构、状态机、SSE、Agent、RAG、配置与 10–12 周计划。
2. [页面与交互设计](页面与交互设计.md)：11 张原图逐页改进、补齐医生端等 27 类页面、设计 Token、路由和交互状态。
3. [数据库与接口设计](数据库与接口设计.md)：33 张逻辑表、关键约束/索引、三端接口、SSE 事件与事务规则。
4. [验收与答辩方案](验收与答辩方案.md)：功能验收、40 项工程/故障场景、离线评测、演示脚本、论文和实习包装。

重点优化：

- 把挂号转化与医生反馈一致性分开，避免把行为数据当医学准确率。
- 明确 MySQL 8 存向量、Java 小规模余弦检索的实现与规模边界。
- 动态本地工具注册与真正 MCP 协议接入分开表述。
- 危急检查和最终数据校验独立于模型及可停用工具。
- 排班默认生成未来新场次，保护已有预约日期和库存。
- 请求固定模型/Prompt/工具/知识版本，同时支持下一次新请求配置生效。

版本：V1.0，2026-10-08。模型供应商、真实医学规则与数据来源未确定，按文档默认范围开发，后续用实测与授权材料完善。
